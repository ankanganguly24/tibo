# Principles

1. **Observe before judging.** Report structural change before making a quality claim.
2. **Evidence travels with the finding.** A decision without a file, symbol, diff, or history reference is a question, not a conclusion.
3. **Approval is explicit.** Keep, reject, and later are human states.
4. **Local by default.** The first useful loop needs no account, network, or model call.
5. **The ledger is not a diary.** Store choices that change future work, not every intermediate thought.
6. **Uncertainty is product output.** Detection limits should be visible.
7. **The diff is the boundary.** Tibo should make scope drift easier to notice, not silently widen the task.
8. **No magic completion.** Passing checks are evidence; they are not approval.
